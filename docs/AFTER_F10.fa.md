# پس از F10

تغییر F10 ظاهری و فرانت است و migration یا dependency جدید ندارد. اگر F09 هنوز روی سرور نصب نشده، ابتدا مراحل migration راهنمای AFTER_F09 را انجام دهید. استقرار روی سرور شما خودکار اجرا نشده است.

پس از دریافت کد و طبق روال انتشار محیط خود:

```bash
git pull --ff-only
npm ci
npm run build
php artisan optimize:clear
```

خروجی جدید build را یکپارچه با manifest منتشر کنید و صفحه را تازه‌سازی کنید. در روشن/تیره و موبایل، متن hero و پیام‌های خطا/خالی را ببینید. پخش را شروع و کاور نوار پلیر را باز کنید؛ همان آهنگ باید ادامه یابد. در تنظیمات motion کمتر را انتخاب کنید؛ ظاهر ثابت باید باقی بماند. پخش در نبود WebGL هم قابل استفاده است.

گام بعدی F11 برای تاریخچه، حالت خصوصی و پیشنهاد قابل توضیح است؛ انتشار عمومی و ماتریس دستگاه واقعی در F16 باقی می‌ماند. rollback فرانت، build و manifest هماهنگ نسخهٔ قبلی می‌خواهد؛ F10 داده یا schema را تغییر نمی‌دهد.
