## فاز ۱ — گیت انتشار پایه

مرورگر واقعی را به محیط دارای PHP وصل کنید. سناریوهای login، import واقعی، انتشار، پخش، seek، تغییر صفحه، روشن/تیره، گوشی و تغییر رمز را اجرا کنید. MySQL CI و تست رقابتی دو درخواست ایجاد حساب روی ظرفیت ۹ و دو تأیید import اجرا شود. معیار پذیرش: هیچ حساب یازدهم و پلی‌لیست دوم ایجاد نشود؛ شبکهٔ کاربر فقط API خود برنامه و assetهای همان origin را فراخوانی کند. کاربر غیرفعال و draft از مسیر مستقیم صوت نیز مسدود باشند.

عنوان کامیت پیشنهادی: `test: verify browser flows and concurrent library invariants`

## فاز ۲ — مدیریت حرفه‌ای محتوا

ویرایش امن متادیتای Track مشترک، تغییر ترتیب و افزودن/برداشتن Track از playlist، آرشیو/حذف کنترل‌شده با تأیید، کاور بهینه‌شده و حذف EXIF، و گزارش خطای دانلودشدنی اضافه شود. تغییر ترتیب باید با قفل playlist و شمارهٔ نسخه انجام شود تا drag-and-drop همزمان داده را جابه‌جا نکند. برای playlist شخصی اعضا، owner/visibility و policy جدید همراه migration طراحی شود.

عنوان کامیت: `feat: add versioned playlist editing and track management`

## فاز ۳ — عملیات و حساب

audit viewer فقط مدیر، بازنشانی رمز با توکن یک‌بارمصرف و انقضا، فهرست نشست‌ها و خروج از دستگاه دیگر، فرمان تشخیص سلامت queue/DB، سیاست پاک‌سازی assetهای بدون مرجع و محدودیت فضای ذخیره‌سازی اضافه شود. معیار پذیرش: عملیات حساس audit دارند؛ cleanup به فایل مورد استفاده یا import آماده آسیبی نمی‌زند؛ اطلاعات رمز در لاگ یا export وارد نمی‌شود.

عنوان کامیت: `feat: add account recovery and library operations dashboard`

## فاز ۴ — تجربهٔ پیشرفتهٔ شنیدن

queue drag-and-drop، پخش بعدی، تاریخچهٔ واقعی شنیدن، sleep timer، تحویل کنترل بین دستگاه‌ها و کلیدهای میان‌بر قابل تنظیم بررسی شوند. waveform با دادهٔ واقعی preprocessing شود. crossfade و gapless با دو Audio یا Web Audio باید پس از آزمایش autoplay، CORS داخلی و رفتار Safari پیاده شود. ReplayGain/بلندی یکسان مستلزم pipeline محاسبه و سیاست فایل اصلی/نسخهٔ پردازش‌شده است.

عنوان کامیت: `feat: expand playback queue and listening controls`

## فاز ۵ — ظرفیت و ارائهٔ رسانه

بنچمارک روی فایل‌های MP3/FLAC/WAV واقعی، شبکهٔ کند، seek موازی و 10 شنونده اجرا شود. در صورت نیاز، X-Accel-Redirect پس از Laravel policy یا storage object خصوصی با URL کوتاه‌عمر و دسترسی محدود اضافه شود. متریک p50/p95 API، RSS، childهای مشغول، خروجی شبکه، خطای Range و طول صف ثبت شوند. هیچ عدد عملکردی بدون اجرای این آزمایش به محصول نسبت داده نشود.

عنوان کامیت: `perf: offload authorized media delivery and measure capacity`

## فاز ۶ — پرداخت نهایی تجربه

تست screen reader، focus order، contrast، اندازه‌های 360/390/768/1440، مرورگرهای Chrome/Firefox/Safari و Android/iOS انجام شود. راست‌چین/چپ‌چین متادیتا، عنوان‌های طولانی، فهرست خالی، 500 آهنگ و خطاهای شبکه بازبینی شوند. سپس مشاهدهٔ کار واقعی چند عضو و رفع اصطکاک‌ها انجام شود. PWA و آفلاین تنها پس از تعریف سیاست cache خصوصی و خروج امن از حساب اضافه شود.

عنوان کامیت: `feat: polish accessible listening experience across devices`

## شیوهٔ ادامهٔ کار

هر فاز در branch مستقل با PR شامل رفتار نهایی، migration لازم، تست معنی‌دار و نتیجهٔ build انجام شود. فایل lock بدون تغییر عمدی وابستگی‌ها بازسازی نشود. مرزهای API، سقف حساب و حریم رسانه باید در هر تغییر حفظ شوند. feature جدید زمانی done است که سناریوی پذیرش آن در محیط هدف عبور کرده باشد.
