# نسخه نمایشی عمومی GitHub Pages

این خروجی از همان کامپوننت‌ها، پوسته، ترجمه‌ها و پلیر React برنامه اصلی ساخته می‌شود. ورودی مجزا در `demo/main.tsx` از مسیریابی hash استفاده می‌کند تا بازکردن و تازه‌سازی لینک‌های داخلی در GitHub Pages کار کند.

کتابخانه و پلی‌لیست‌ها، جستجو، پخش/مکث، صف، تکرار/تصادفی، علاقه‌مندی، ذخیره فهرست، متن نمونه، حالت روشن/تیره و تنظیمات زبان قابل امتحان‌اند. فایل‌های صوتی کوتاه با فرمول‌های سینوسی در `demo/generate-audio.mjs` ساخته می‌شوند؛ موسیقی هنرمندان واقعی یا داده کاربران در این خروجی نیست. همه تغییرات نمایشی تنها در localStorage همان مرورگر نگهداری می‌شوند.

بنر دائمی، نمایشی بودن خروجی را اعلام می‌کند. بازدیدکننده یک عضو نمونه با دسترسی listener است. transport این ورودی فقط درخواست‌های همان مبدأ به `/api/v1` را به داده محلی وصل می‌کند؛ از ورود، رمز، آپلود، مدیریت واقعی و درخواست‌های ناشناخته پشتیبانی نمی‌کند. فایل `resources/js/lib/api.ts` و کنترل‌های session/CSRF برنامه اصلی تغییر نکرده‌اند. Service worker برنامه اصلی در این ورودی ثبت نمی‌شود.

این خروجی، استقرار Laravel یا تأیید production نیست. PHP، MySQL، queue، MFA، مجوزها، آفلاین واقعی و ارتباط بین دستگاه‌ها در GitHub Pages اجرا نمی‌شوند. خطاهای CI برنامه اصلی باید جداگانه رفع شوند و موفقیت انتشار نسخه نمایشی جای تأیید آن آزمون‌ها را نمی‌گیرد.

## ساخت

```bash
npm ci
npm run test:demo
npm run build:demo
```

خروجی در `dist-demo` است. `DEMO_BASE_PATH` مسیر پایه را تنظیم می‌کند و مقدار پیش‌فرض آن `/ahang-khatkesh/` است. workflow اختصاصی `pages-demo.yml` تنها همین خروجی استاتیک را منتشر می‌کند. فایل‌های PHP، `.env`، مسیر ذخیره‌سازی خصوصی و دیتابیس جزو خروجی نیستند. تغییرات داده نمایشی را می‌توان با دکمه «شروع دوباره» پاک کرد.
